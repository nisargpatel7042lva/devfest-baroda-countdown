# DevFest Baroda 2026 — Main Screen Countdown

Live countdown for the main stage screen: a normal timer, the designed 60 → 1 numbers for the last minute, the DevFest Baroda logo reveal, then an optional sponsor video.

**Run it:** open the GitHub Pages link in Chrome or Edge, set the duration or start time, optionally pick the sponsor video file, and click **Start fullscreen**.
Everything is in one `index.html`, so it also works offline: download it and double-click.

Keys: `Space` pause/resume · `←`/`→` −/+1 min · `T` jump to 1:10 left (test) · `V` play sponsor video · `M` mute · `F` fullscreen · `Esc` then `S` back to setup.
